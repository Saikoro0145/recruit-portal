# インターン管理アプリ 設計ドキュメント

---

## 概要

サマーインターンの締切・日程・企業情報を一元管理するWebアプリ。
カレンダーで日程を把握し、企業ごとのメモ・アカウント情報・ファイルも管理できる。

---

## 技術スタック

| 用途 | 採用技術 | 理由 |
|---|---|---|
| フレームワーク | Next.js 15（App Router）+ TypeScript | SSR・API Routes・Server Actions が使える |
| スタイリング | Tailwind CSS + shadcn/ui | ユーティリティ + 高品質UIコンポーネント |
| カレンダー | FullCalendar（@fullcalendar/react） | 見た目が良い・月/リストビュー・期間バー対応 |
| データ | JSONファイル + Server Actions | ファイル直接編集も可・サーバー側でread/write |

## 画面構成

```
┌─────────────────────────────────────────┐
│ Header（タイトル・ナビゲーション）            │
├───────────────┬─────────────────────────┤
│               │                         │
│  サイドバー    │  メインコンテンツ          │
│  - 企業一覧   │  - カレンダー             │
```

### 画面一覧

| 画面 | パス | 内容 |
|---|---|---|
| カレンダー | `/` | 月ビュー・締切と期間を表示 |
| 企業一覧 | `/companies` | 企業カード一覧・業界別グループ・ステータス表示 |
| 企業詳細 | `/companies/:id` | メモ（Markdown）・イベント一覧・アカウント情報・ファイル |
| イベント追加/編集 | モーダル | 締切・インターン期間の登録 |

## データ構造

### `data/categories.json`

```json
[
  { "id": "finance", "label": "金融", "color": "#3b82f6" },
  { "id": "sier",    "label": "SIer", "color": "#8b5cf6" }
]
```

### `data/companies.json`

```json
[
  {
    "id": "example",
    "name": "サンプル企業",
    "category": "finance",
    "color": "#e74c3c",
    "notes": "## メモ\n...",
    "url": "https://...",
    "mypageUrl": "https://...",
    "loginId": "",
    "readmePath": "finance/example/README.md"
  }
]
```

`readmePath` を設定すると、`RECRUIT_ROOT` 配下の Markdown ファイルをメモとして読み込む。

### `data/events.json`

```json
[
  {
    "id": "example-deadline",
    "companyId": "example",
    "title": "ES締切",
    "type": "deadline",
    "start": "2026-06-01",
    "end": "2026-06-01",
    "status": "pending",
    "note": ""
  }
]
```

**type の種類**

| type | 説明 | カレンダー表示 |
|---|---|---|
| `deadline` | 応募・ES・テスト締切 | 単日・警告アイコン |
| `internship` | インターン実施期間 | 期間バー |
| `selection` | 面接・GD等の選考 | 単日 |
| `event` | 説明会・セミナー | 単日 |

**status の種類**

| status | 説明 |
|---|---|
| `pending` | 未対応 |
| `applied` | 応募済み |
| `in_progress` | 選考中 |
| `passed` | 合格 |
| `rejected` | 不合格 |
| `done` | 完了 |

## 主要機能

### カレンダー
- 月ビュー・リストビュー切り替え
- イベントを企業カラーで色分け
- 締切は単日マーカー、インターン期間はバー表示
- クリックでステータス変更・編集・削除

### バッティング検出
- internship 同士の期間重複を自動検出してサイドバーに警告表示

### 締切カウントダウン
- サイドバーに直近の締切を一覧表示（3日以内は赤、7日以内はオレンジ）

### 企業メモ
- Markdown で記述・プレビュー表示
- `readmePath` 設定時は外部ディレクトリの Markdown と同期

### アカウント情報管理
- マイページ URL・ログインID を企業ごとに保存
- ログインID はワンクリックコピー対応

### ファイルブラウザ
- 企業フォルダ内のファイルを一覧表示・macOS でそのまま開く

### 業界カテゴリ管理
- カテゴリを動的に追加（名前・カラー設定）
